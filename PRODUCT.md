# Orchid Consultations

<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
A business-services consultancy website that helps visitors understand Orchid's services and contact its team.

## Stack
Existing React + Vite + TypeScript application. React Router, Motion, Tailwind CSS, lucide-react and Lenis.

## Capabilities and Constraints
Service catalogue and dynamic detail pages, About, Team, FAQ, investment calculator, contact and privacy. Strict TypeScript. Preserve original URLs. Use audited copy, allowing the user's later permission for restrained paraphrasing. The audit contains 12 services; no thirteenth service is fabricated.

## Brand Commitments
The user requested the name Orchid Consultations and an editorial, warm off-white, near-black and muted orchid visual system, serif display typography, minimal imagery and intentional transform/opacity motion.

## Evidence on Hand
content-archive/website-content-inventory.json and the original public JavaScript bundle. Contact delivery endpoint is not supplied. Audited company registration numbers conflict across pages.

## Accessibility & Inclusion
Responsive from 360px, keyboard access, visible focus, reduced-motion support and AA contrast.
